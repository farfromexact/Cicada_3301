# FEED-010：把操作隐喻收敛为可辨别机制

本轮输入归档于 sources/feed010/user-proposal.txt，来源时间、固定版本与 SHA-256 见 sources/feed010-manifest.json。
材料中“让 Codex 检验所有读序”等句子按研究建议处理；本次只执行两座已知方阵的机械核查，没有启动未解页批次。
新增价值在于把 C008 的内外联想细化为读序、边界和自生密钥三条机制方向；材料的主观排序并不等于实验优先级已经得到证据支持。

## 与既有证据衔接

| 材料方向 | 当前证据与限制 | 处理 |
|---|---|---|
| WITHIN / CIRCUMFERENCE / 环与螺旋 | C008 为推测；C011 已证明 LP1/05 中心对称。明确方阵可定义几何，但普通文字不能任意补齐成矩形 | 本轮只核查两座 5×5 方阵的读序、逆映射和去重；隐藏读序未验证 |
| END / SELF / 删除 | C017 的明文 F 是保留且不消费流，不是删除符文。额外正常加密的密文 F 不能全部跳过 | 保留掩码/跳位机制提案；不做删除全集搜索。H001/H007 范围不扩大到全部 omission |
| WORDS / NUMBERS 双层 | C002/C003/C012 支持保留符文序号、GP 值与结构；不能推出每页都有额外密钥 | 数值提取可作观测，需固定原始版面/真实词边界，不能从清理英文重新算数 |
| TOTIENT / 再编码 | C004/C013 已复现位置素数流；多层加密及 LP1 为 key schedule 仍是猜想 | 先定义层数、中间表示和独立可测预测，不能因乱码无限加层 |

| CONSUMPTION / PRESERVATION / ADHERENCE | 文学三分类没有唯一符文分类或组合算子 | 暂不执行。删掉低分符文可能自动改善分数，须固定长度/掩码对照与可恢复信息 |
| QUESTION / 自生密钥 | C018 和 H006/H007 已覆盖部分边界约定，不是全书版式结论 | 自生密钥须先固定原始字节或符文序列、输出编码、作用范围；同页挑规则不能算独立验证 |
| INSTAR / 多阶段 | 词项存在不能指定变换数量、方向和顺序；不同 LP1 页使用不同方法不证明每页叠全部方法 | 保留猜想；中间结果须提前有结构预测和对照，不能只凭“还不是英语”继续补层 |

F 的 index=0、GP=2；prime position、GP prime value、phi(cell_sum)、phi(stream_prime) 是不同对象。
数阵的十进制格值不是单个原始符文，取 mod29 得到的序列必须标为派生值。整词求和或取模有损，不能直接声称得到唯一可逆文本。
语义词 CIRCUMFERENCE 与来源密钥的 F/C 差异已有 C006；本次不静默将 FIRFUMFERENFE 改拼写。
H008 的原始符文相等、边界和跨页重复阴性不覆盖新几何，也不能解释为“简单方法全失败，必须复杂密码”。

## 实际小闭环：FEED010-geometry-audit-v1

先冻结 hypotheses/FEED010-geometry-audit-v1.json，再运行 scripts/check_geometry.py。输入是固定 iBot 05/16 原始首个转写块；05 从原符文逐格 GP 求和，16 读原十进制格值，未使用 Cleaned up Plaintext。
16 的 25 格与本次附件数阵完全一致；尚未逐格独立校对 16 原图。这是转写与数值机械核查，不是完整 LP1/16 解密回归。

每座数阵固定 16 个具名路径：左上顺时针外环→内环→中心，施加 D4 的旋转/转置，再对整个路径倒序定义 outward。
这不是“所有可能的内外读法”；各层独立起点、任意连接、分层密钥、矩形拼排均未测试。名义 32 路径 × 3 表示 = 96 个机械检查输出。

结果：两座阵均只有 8 个不同整数读序；mod29 和 phi(cell_value) mod29 各仍 8 个。每个视图都保持原直方图、可逆放回原位置，逐格映射与重排可交换。
全不同坐标标签对照保留 16 个不同读序；将右下角加一的对照破坏中心对称，也恢复为 16 个不同整数读序。说明等价性来自输入结构，而不是遍历实现漏掉方向。
两阵外/内/中心环长度均为 16/8/1；环和分别 3286/1788/91、10404/5292/809。这里只报告确定性算术，不解释这些和是密钥或具有显著性。

本轮最有用的限制：纯重排不改变单符文频率，任意位置无关 unigram 评分都无法选择读序；逐格映射后的全局频率仍如此。
phi 的新增碰撞不消除这一不变性。若后接位置依赖的密码流，映射可不再与重排交换，须明确新机制、顺序和对照，不能拿当前不变性排除复合密码。
已知中心对称条件下，环上的对径重复也是必然现象；把它与完全随机打乱的数阵比较可能只重新发现已知对称性。后续零假设须控制已有结构。

## 下一步三个具体提案（均未执行）

1. **几何读序的可检出性**：仅对已校对的显式网格，比较固定环/螺旋路径与基线。先在独立生成的带顺序关系正例及保留中心对称的负例上冻结位置敏感指标、去重与家族门槛，再开未知数据。鉴别价值：判断是否有超出已知对称性的顺序信息；普通单词版面不强行造网格。正式适用集合必须先盘点，不等于默认只有这两页。
2. **保留而不推进与真正删除的区别**：先在已知 DIVINITY/56 上量化 F 时钟机制对结构指标的影响；把删除输出作为显式信息丢失对照，保留位置掩码，不能当同一解法。鉴别价值：校准 H008 指标在已知跳位机制下的检出能力，说明“没结构”的证据力度。这是新测量问题，不必重复 H001 的已完成逐符文比较。
3. **边界自生密钥的独立预测**：候选只考虑明确网格外环给内环提供密钥，起点/方向/内外对应必须由独立版面依据约束；定义不成就不跑。用保留环边际分布与已知对称的对照及不参与规则选择的对象验收。鉴别价值：将“自己产生 key”缩为边界能否预测内部，避免从 length/sum/hash 任意选映射总能拟合。散列任意扩展等没有依据的分支暂不优先。

以上是提案，不是冻结批次。广义“内外、删除、自生”目前并不能整体证伪；只有输入、算法、参数、预测与覆盖明确的实例才可被反驳。未命中不自动“迅速放弃”整个方向。
